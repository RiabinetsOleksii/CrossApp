## 📌 Мета роботи
Підготувати робоче середовище для розробки крос-платформних застосунків на платформі .NET, ініціалізувати систему контролю версій Git, обрати предметну область для наскрізного проєкту та налаштувати базову структуру Solution і консольного застосунку.

---

## 🏢 Предметна область
* **Обраний домен:** Склад.
* **Основні сутності:** 
  * `Product` (товар)
  * `StockBatch` (партія товару)
  * `Warehouse` (склад)
  * `Movement` (переміщення товару)
* **Призначення застосунку:** облік залишків товарів по партіях на складах та фіксація історії переміщень товару між об'єктами. Доменне рішення є фіксованим і розширюватиметься в наступних лабораторних роботах до REST API та веб-інтерфейсу.
