# Питання до захисту лабораторної №8 — короткі відповіді

1. **Що робить await? Створює потік?** Чекає завершення Task без блокування потоку; новий потік сам по собі не створює.
2. **Чому Task.Run(File.ReadAllText) — не async I/O?** Файлове читання лишається блокувальним, просто працює в іншому потоці. Потрібен FileStream(useAsync:true) або ReadAllTextAsync.
3. **Чому небезпечні .Result і .Wait()?** Блокують потік, у деяких контекстах можуть спричинити deadlock; краще await.
4. **Чому не async void?** Його не можна await, а винятки важко перехопити. Виняток — обробники подій.
5. **OperationCanceledException — помилка?** Ні, зазвичай очікуваний сигнал скасування; обробляємо окремо і повідомляємо користувача.
6. **Хто створює токен, а хто перевіряє?** Cli створює CancellationTokenSource; Service та Importer передають і перевіряють токен.
7. **DomainException чи ArgumentException?** DomainException — заборонений перехід стану Sensor; ArgumentException — порожня модель або неправильний інтервал.
8. **Навіщо InnerException для JsonException?** Щоб зберегти первинну причину та стек. Технічну JsonException у нашому імпортері не маскуємо як DomainException, а передаємо вище.
9. **Чому InMemorySensorStore в тестах?** Тести швидкі, ізольовані від диска та інших запусків.
10. **Theory/InlineData проти кількох Fact?** Один метод тестує кілька наборів даних без дублювання коду.
11. **Як перевірили подію один раз?** Підписалися на Changed, додали сенсор, перевірили `Assert.Single(events)` і тип події Added.
