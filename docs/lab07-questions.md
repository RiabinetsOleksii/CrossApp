# Питання та короткі відповіді для захисту лабораторної №7

1. **Що виконується відкладено, а що одразу?**
   `Where`, `Select`, `OrderBy`, `GroupBy` формують відкладений запит. `ToList`,
   `Count`, `Sum`, `Average`, `Max`, `First` запускають його виконання.

2. **Що буде, якщо змінити джерело перед ToList?**
   Нові або змінені елементи можуть потрапити в результат при наступному переборі.
   У нашому демо це видно за двома різними значеннями `Count()`.

3. **Навіщо ToList, якщо результат використовується двічі?**
   Щоб не виконувати запит повторно й не читати повторно файл або колекцію.
   `ToList()` фіксує готовий результат.

4. **Які оператори буферизують колекцію?**
   `OrderBy` та `GroupBy` потребують зчитати всі елементи, тому можуть
   використовувати багато пам'яті на великих наборах.

5. **Різниця між Count та Count()?**
   `Count` — готова властивість колекції. `Count()` — метод LINQ, який рахує
   елементи запиту; для деяких колекцій він може оптимізувати підрахунок.

6. **Навіщо DTO замість Sensor?**
   DTO повертає тільки поля звіту й захищає зовнішній контракт від змін у
   внутрішній доменній моделі.

7. **Що робить Average на порожній колекції?**
   Для `int` кидає `InvalidOperationException`. У `Totals` ми спочатку перевіряємо
   `list.Count == 0` і повертаємо чотири нулі.

8. **Навіщо ThenBy у Top-N?**
   Якщо два сенсори мають однаковий інтервал, `ThenBy(Id)` встановлює
   передбачуваний порядок незалежно від порядку вихідної колекції.

9. **Чим відрізняються First, FirstOrDefault і Single?**
   `First()` бере перший і кидає виняток, якщо нічого немає.
   `FirstOrDefault()` у такому випадку повертає значення за замовчуванням.
   `Single()` вимагає рівно один елемент: кидає виняток при 0 або більше ніж 1.

11. **Що зміниться, коли перейдемо до IQueryable у EF Core?**
    Запит виконуватиме провайдер бази даних і, де можливо, переводитиме LINQ в SQL.
    Не кожен .NET-вираз можна перекласти в SQL; зараз у нас тільки LINQ to Objects.

12. **Де звичайний цикл кращий за LINQ?**
    Там, де потрібні послідовні побічні дії: наприклад, вивід рядків звіту в
    консоль чи запис журналу. Для фільтрації та групування краще LINQ.
